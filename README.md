# Brute-Force-Login-simulator


## Description
This project simulates a brute force attack against a login system using PowerShell. It was created as part of cybersecurity practice to understand how password attacks work.

---

## Tools & Technologies
- PowerShell
- Kali Linux (for practice environment)

---

##  How It Works
- A list of usernames and passwords is provided
- The script attempts every password for each user
- If the correct password is found, the script reports a successful login

---
